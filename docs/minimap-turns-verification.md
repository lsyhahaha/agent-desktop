# Minimap 一轮一条与居中修正

日期：2026-10-31。修正上一版“轮内每条消息均画线”和固定高度内顶部排布的问题。

- 每次User提问仅生成一条稳定ID记录；回复、工具和事件合并到该轮预览，并参与实际内容范围计算，不再额外占线。当前生成轮次计入最近20轮，原文完整保留，点击定位提问。
- 按记录数收紧导航高度，整组在消息区域垂直居中；单轮也居中。预览卡片使用聊天区域边界计算可用高度，不能随导航高度缩短而被裁成24px。
- 动画使用requestAnimationFrame按帧间隔指数追随目标：悬停40ms时间常数、离开65ms，去掉每次指针更新都会重启的220ms CSS过渡。CSS仅接收横向transform，减少动态效果时直接到达目标；卸载仍清理动画帧。
- 构建（含类型检查）与差异格式检查通过。独立临时Electron窗口用受控25轮/50条消息、8条同轮工具，验证仅20条导航、原文50条保留；第26轮生成时窗口前移；默认等长、磁吸衰减、两线之间放大、移出恢复、定位、键盘、稳定DOM、居中及浅深色边界均通过。未编写单元测试。
- 另外覆盖单轮预览高度，避免居中修复引入预览裁切。全部使用受控UI投影，没有真实模型请求、工具执行或用户数据操作。

[结果](evidence/minimap-turns-acceptance.json)；[深色效果](evidence/minimap-turns-dark.png)、[浅色效果](evidence/minimap-turns-light.png)。没有进行帧时间基准，不宣称实测恒定60fps；真实模型长稳与跨平台不在本轮范围。

## 预览摘要样式调整

移除可见角色标题和拼接的角色前缀，提问使用亮色且最多一行，回复使用淡色且最多三行，超出省略；保留不可见的可访问名称。预览只取限长的提问/回复，不展示工具输出或完整长文，不改变原文、轮次筛选、动画和定位。

构建与格式检查通过。临时窗口实际验证无标题、两种文字色调不同、一行/三行样式及回复实际高度；原有20轮筛选、居中、磁吸、定位、键盘、流式稳定性和单轮预览检查同时通过。没有调用真实模型或编写单测。[本次结果](evidence/minimap-summary-acceptance.json)；[已查看的深色效果](evidence/minimap-summary-dark.png)。
