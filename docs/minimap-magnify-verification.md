# Minimap 最近20轮与磁吸放大验收

日期：2026-10-31。本文件记录上一版轮内多标记实现；当前一轮一条、居中与逐帧跟随修正见 [轮次修正验收](minimap-turns-verification.md)。对现有组件局部调整；Runtime、协议、数据库、原文消息与发送逻辑未改动。没有新增依赖。

## 当前行为

- `App.tsx`/`ToolRecords.tsx` 为既有DOM投影补充稳定消息/工具ID和runId；Minimap从User消息取得最近20个轮次ID，仅过滤导航条目。轮内多条回复和工具仍归于同一轮，生成中轮次计入。已加载正文全部保留；未加载历史仍不自动获取。
- 标记使用稳定ID作React key，默认12×3px、圆角2px、净间距7px、左起点0。SVG圆角矩形避免线帽改变实际测量宽度。44px绝对定位交互区容纳36px放大，不挤占正文。
- 在30px半径内按指针与中心的实际距离连续衰减，中心36px、相邻约26px、次邻约18px。requestAnimationFrame合并直接设置线条scaleX，220ms过渡，不改变标记纵坐标，不因mousemove重渲染App。移出恢复12px，prefers-reduced-motion关闭过渡。
- 保留现有200ms预览调度、纯文本卡片、DOM跳转和主聊天滚动监听。等距缩略坐标与真实DOM位置作分段转换，视口指示器表达真实阅读位置；历史早于保留范围时不伪造活跃线。
- 工具密集时，只在缩略区内部滚动并隐藏额外滚动条，保持3px线高和7px净间距；键盘自动将选中的标记滚入可见区域。预览卡片仍在滚动区外，不被裁切；间隙桥接保留。
- 卸载清理待执行动画帧、指针、观察器、事件和预览计时器；没有自动发起模型请求或工具执行。

## 实际验收

Electron 45.1.0独立临时userData，使用25轮/50条受控消息和同轮8条工具结果，随后追加正在生成的第26轮；没有真实密钥、模型请求、工具执行或用户项目访问。

- 25轮只展示最后20轮；真实正文仍有50条；工具多条不增加轮数。追加第26轮后窗口前移、正文仍有52条。
- 实际测量全部默认标记12×3px，中心距10px（净间距7px）；悬停中心/两级邻近宽度约36/26/18px，两线之间可同时部分放大，左起点不动。
- 移出后恢复12px；预览仍指向正确消息，点击定位正文距聊天视口顶部16px；键盘Home定位最早保留轮，End可访问工具密集区末项并在缩略区内滚动。
- 流式追加文本后，同ID的标记DOM节点保持同一对象；当前生成轮被纳入筛选。切换空会话清理预览与导航。
- 默认1320×860深色、最小1000×680浅色实际查看截图，预览300px宽/最大220px高，无整页横向溢出，输入框仍100px高。
- 通过应用内CDP模拟prefers-reduced-motion，实际计算过渡时长为0s。构建（含类型检查）及 `git diff --check` 通过。未编写单元测试、未提交Git。
