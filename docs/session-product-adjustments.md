# 本轮产品调整观察

- 使用 computer use 打开 ZCode，实际观察到工作区独立的新建任务入口（⌘N）、空任务列表、项目选择、搜索及筛选入口。
- 实际展开的筛选菜单包含：按项目、按分组、最近更新。当前 ZCode 没有已有任务，因此未验证其真实历史任务切换、改名或归档行为，不把这些行为当作观察结论。
- 本项目按需求实现最小内存会话：新建、切换、改名、按标题搜索、最近更新时间排序；不照搬自动化、插件、分组或持久化。
- read_file 改由 Runtime 根据已授权工作区默认提供；前端没有开关，也不能通过 send 参数改变工具可用性。每次读取审批、路径校验、取消和运行上限保持不变。
- 一次性受控集成验证：独立历史、新建保留、空草稿复用、改名、过期目标发送拒绝、运行中切换拒绝、内置读取工具审批和工作区隔离通过；不视为本轮真实模型验收。

## 实现与边界

- 任务目录由 apps/runtime/src/sessions.ts 拥有，复用每个 Agent 的既有循环；单个时刻仍只运行一个任务。
- 首条消息形成任务标题，空草稿不进入侧栏；重复新建复用未发送草稿。支持按标题搜索和手动改名，未实现归档、删除、分组或数据库持久化。
- send 必须携带目标 sessionId，Runtime 拒绝过期会话发送；Main 只接受原生选择器授予的工作区路径。切换事件与命令回包按整体会话 revision 更新。
- read_file 不再接受客户端 tools 开关。有工作区时内置提供，无工作区不向模型暴露；保留逐次审批及所有读取限制。
- 为20个内存会话限制单轮显示输出64Ki字符，并在新轮次接纳前限制显示历史20万字符，避免失败轮次绕开上下文预算。不是已测RSS指标。
- 类型检查与完整构建通过。未新增依赖或单元测试，未提交Git。

## 实际界面复查

- 新版Electron窗口已启动；首页截图确认输入区没有read_file/读取前确认开关，模型选择与发送仍保留。
- 实际窗口已显示真实任务标题、搜索入口、改名入口和默认读取工具结果。观察到用户自主触发的项目理解任务成功读取README.md与package.json；本轮自动化没有为此另行发送模型请求或操作密钥。
- 新建、切换、独立上下文和改名的后端行为已用一次性受控集成验证。computer use期间存在窗口定位/控件状态延迟，未把未确认的点击当作完整UI验收，也未更改用户当前任务名称或删除其内容。
- ZCode的computer use观察仅覆盖当前空任务工作区及筛选菜单，未配置ZCode模型或发送任务。重命名功能是本项目的最小设计，不能表述为已验证的ZCode菜单行为。
