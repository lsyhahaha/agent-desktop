# Conversation Minimap 验收

日期：2026-10-31。此文件记录初版；当前最近20轮、等距缩略线与磁吸放大规则及验收见 [磁吸优化验收](minimap-magnify-verification.md)。仅新增renderer导航投影，未修改模型、工具调度、权限、存储或IPC协议。

## 实现

- `ConversationMinimap.tsx` 根据 `data-minimap-kind` 标记的真实DOM位置/高度生成缩略线；`App.tsx` 标记用户/Agent正文、审批、停止与用量事件，`ToolRecords.tsx` 标记工具调用与结果。折叠的工具输出用已显示详情入口的位置作为定位点，预览取当前已加载输出。
- 导航绝对定位并紧贴聊天区域左边线，容器left与缩略线x1均为0，无额外水平间隔，正文宽度不变。32px命中区、2px缩略线、20px最大线宽；高度随视口变化、最大480px。普通线低对比度，工具线更暗更短，当前视口和活跃消息单独标示。
- 悬停200ms显示300px宽、最大220px高的纯文本卡片，预览限1200字符；可将鼠标移入预览滚动阅读。点击按实时原文坐标定位，不执行消息中的代码或跳转链接。
- 单个键盘入口：方向键浏览，Home/End首尾，回车/空格定位，Escape关闭。可访问位置、总数和角色标签随选择更新；焦点不跳到输入框。
- MutationObserver/ResizeObserver观察消息内容及容器，变化80ms合并测量；滚动通过requestAnimationFrame合并，只更新视口位置。组件卸载清理全部观察器、计时器和帧回调。测量不会扫描数据库或加载未展开历史。

## 实际验收

- Electron 45.1.0独立临时userData，既有事件通道注入30条长短混排消息、工具调用/结果和完成事件，共36个标记。都是受控UI样本，无真实模型请求、工具执行或用户项目读取。
- 空会话不显示导航；检查缩略间距随DOM高度变化，非平均分配，默认正文仍780px宽。
- 原生鼠标检查100ms不提前预览、200ms后预览可见、卡片300px宽/不超过220px、进入卡片后仍可阅读；点击对应缩略线后正文距离消息视口顶部16px，视口指示器同步移动。
- 原生键盘检查Home/回车定位首消息、方向键预览下一条、Escape关闭。受控流式增量改变缩略位置，阅读历史时没有被强拉至末尾；展开命令输出后导航仍有效。
- 默认1320×860深色、最小1000×680浅色实际查看截图，预览不越界/不覆盖输入区、无整页横向溢出，输入框仍100px高。切换到空会话后导航和预览均清理。
- 构建（包含类型检查）与 `git diff --check` 通过。未编写单元测试或提交Git。

## 边界

仅覆盖当前已加载消息及已展开历史工具记录，不代表持久化数据库中的全部对话。密集消息可能出现缩略线重叠，可用键盘逐项定位。未验证真实模型长时流式、极限规模性能、其他操作系统、读屏软件或所有缩放比例；不把受控UI验收表述为完整Agent端到端验收。
